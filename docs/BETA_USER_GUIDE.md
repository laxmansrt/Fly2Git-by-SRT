# Fly2Git Private Beta — User Quick Start Guide

Welcome to the private beta of **Fly2Git by SRT** (`v1.1.6-rc.1`).

> **Note to Beta Testers**:
> The primary purpose of this beta is to test the actual product mechanics, friction points, and real-world reliability across platforms — not merely to collect passive usage statistics. Your direct experience and issue reports are invaluable.

---

## 7 Steps to Get Started

### 1. Install Fly2Git
- Load the unpacked extension directory into Chrome (`chrome://extensions` with Developer mode enabled) or install via the provided private beta Web Store link.
- Pin the Fly2Git icon to your Chrome toolbar for quick access.

### 2. Connect GitHub
- Click the Fly2Git icon to open the popup.
- Click **Connect GitHub** and complete the OAuth authorization.
- Select the target GitHub repository where you want your solutions committed.

### 3. Select Platforms
- Choose the coding platforms you practice on (e.g., LeetCode, GeeksforGeeks, HackerRank, Codeforces, CodeChef, AtCoder, SPOJ).
- Basic accounts support up to 2 active platforms; Pro beta cohorts have full multi-platform access enabled.

### 4. Solve a Problem
- Navigate to your chosen coding platform and solve any problem.
- Submit your code and wait for the **Accepted** verdict.

### 5. Check GitHub
- Watch the Liquid Glass in-page notification confirm the sync.
- Open your target repository on GitHub: verify that the code, README with problem description, and commit notes were created cleanly in their respective directory.

### 6. Try AI Features
- Open the Fly2Git popup on a problem page or view recent solutions.
- Test **AI Analyze**, **Explain**, or **Hint** to inspect solution complexity and alternative approaches.

### 7. Report Any Issue
- If anything looks confusing, fails to sync, or behaves unexpectedly, click **Report a Problem** or **Copy Diagnostics** directly from the popup.
- Diagnostics are automatically scrubbed of all tokens and passwords.
